The research

Input preparation is a configuration choice.

Method rankings change across tasks and execution settings. Increasing intervention intensity can reduce utility, while task-level gains and losses can cancel in an aggregate score.

The paper evaluates paired task outcomes, configuration sensitivity, and conditional routing. Official scores measure task outcomes; Valid scores also require successful method completion and the recorded information-access checks. Both are retained in the results below.

Current manuscript

To Optimize or Not to Optimize: When Input Optimization Helps and Hurts LLM Agents

Chuang Zhao · Xiaomeng Li

Method catalog

Five kinds of input intervention.

The published package contains more methods than the paper's 23-method study. Profiles declare their implementation, dependencies, and execution requirements.

Get started

Use a saved configuration,
not a hidden setup.

Install and inspect

Install the published release, inspect available profiles, and read its bundled guides.

python -m pip install agentinputlab==0.1.0a17
agentinputlab doctor --offline --json
agentinputlab smoke --json
agentinputlab list --releases
agentinputlab docs configuration

Configure through Studio

The installed package includes a local web interface for generating, importing, editing, and running configurations.

agentinputlab-studio --workflow-root ./studio-workflows

Open the printed /workflows URL. Keep the service on localhost; enter credential environment-variable names, not API keys, in configurations.

Prepare, execute, and score

Start from a configured run.json, choose a supported benchmark, and inspect prerequisites before execution.

agentinputlab workflow init --run-config run.json \
  --benchmark bfcl.v3.simple_python --limit 1 > workflow.json
agentinputlab workflow inspect workflow.json
agentinputlab workflow launch workflow.json --execute \
  --allow-network --output-dir workflow-run

Choose your runtime

Configure a local model, vLLM server, OpenAI-compatible endpoint, or supported provider API. Budget, seed, generation settings, retrievers, and method parameters live in the configuration.

agentinputlab show plan.plan_and_solve.ps_prompt --parameters
agentinputlab config init > run.json
agentinputlab config validate run.json
agentinputlab docs workflows
agentinputlab docs studio-workflows

Execution is local to your environment. This public website presents documentation and paper aggregates. It does not accept API keys or run models. Model-backed workflows use your configured services and resources; prompt-only workflows return an input patch rather than a scored task result.

Saved runs are reusable. Resume uses the saved run configuration and execution records. Completed attempts, including genuine failures, are not repeated. Unsupported combinations and missing resources are reported before model execution.
